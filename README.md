# 3v3 PvP 匹配机制模拟器

浏览器中的匹配机制实验台。支持经典团队 Elo、纯表现分、OpenSkill ordinal，以及包含定段赛、情绪和风险隔离的完整方案。

## 开发与验证

需要 Node.js 22.12+，或 Vite 支持的更新版本。

```sh
npm ci
npm run dev
npm test
npm run build
npm run preview
```

`npm run build` 输出 `dist/`，`base: './'` 支持域名根目录及子路径部署。

## 项目结构

- `src/engine.js`：模拟状态、匹配、结算与统计；从原发布包整理为可维护模块，并修复算法问题。
- `src/defaults.js`、`src/config.js`：参数默认值、控件定义和对比方案。
- `src/simulation.worker.js`：后台模拟、运行节奏和实验快照。
- `src/main.js`、`src/style.css`：控制台、玩家明细、A/B 对比和方案说明。
- `src/visuals.js`：Canvas 匹配回放与图表；动画按显示帧绘制，数据快照最多每秒 10 次。
- `tests/engine.test.js`：随机群体一致性、复现、Elo 对称性、队列、开关和数值稳定性检查。

## 模拟规则与复现

- 同一世界参数和种子生成相同的初始玩家；各方案的评分状态可不同。入队、漂移、表现和检测采用按玩家及时间索引的随机事件。
- 撮合策略会改变对手、参赛次数与情绪，因此两组后续轨迹允许自然分化。
- “世界中存在作弊玩家”决定是否生成作弊玩家，“启用反作弊隔离池”决定是否防护。两者独立，便于进行公平对照。
- Elo 两队根据同一份赛前期望结算。无额外加成且失分系数为 1 时，总分守恒。
- 匹配队列每 tick 缓存评分排序，有限尝试 16 位等待最久的候选，避免单个极端玩家阻塞队列。
- 群体、初始评分或评分方案改变会重开；其他参数即时应用，热更新和新手注入按 tick 记录在 `events` 中。
- 导出包含初始配置、当前配置、参数变更、新手注入、种子与结果。使用初始配置启动，按事件顺序在对应 tick 应用参数变更和新手注入，即可重放同一路径。
- 统计区分底层水平估计与实际匹配分。完整方案撮合使用定段分或展示段位分，水平误差使用底层 R 与真实水平比较。
- 排队时长按 tick 统计；当前活跃占比包含回流，不等同于真实产品留存率。单次实验不提供统计显著性结论。

## 部署到 GitHub Pages

仓库包含构建部署工作流。推送源码后，在仓库 **Settings → Pages → Source** 选择 **GitHub Actions**。工作流先执行测试，再构建并发布 `dist/`。

如需手动发布，仅上传 `dist/` 内的构建产物。源码入口不能直接由普通静态服务器执行；开发使用 Vite，生产使用构建产物。

项目不依赖服务端，不上传玩家模拟数据。当前代码变更本身不会推送或修改线上站点。
